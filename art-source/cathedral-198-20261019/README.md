Reproduction uses a disposable checkout of the pre-repair base, never a live editor checkout:

1. Build `art-source/tools/blender/build_church.py` with Blender, `--out <external>/church.glb --no-shots`; import with `native-godot/scripts/replace-church.ps1 -SourceModels <external> -Port <isolated-port>`. The intake hashes all unrelated model files and manifest entries before/after.
2. Apply `recovery/cathedral-198-r2.json` and `cathedral-198-r2-structure.json` with `cut-recovered.py`. The first preserves the original paintings and appends the five marble parts. Run `scripts/altar-shell-cut.tscn -- --record <fresh-external>` for the guarded town-shell cut.
3. Export `ct_marble_w,ct_marble_b` through `scripts/audit-stone-corners.gd --out <external-audit> --materials ct_marble_w,ct_marble_b`. Run Blender `-P scripts/repair-cathedral-marble.py -- <audit> <candidate>`, then `scripts/stone-corners-promote.tscn -- --candidate <candidate> --record <fresh-record> --backup <fresh-backup>`. The promoter rejects stale source hashes; it retains existing metadata and all untouched packed surfaces.
4. Regenerate/promote the shared marble pictures as described in `native-godot/assets/materials/cathedral-marble-20261019/README.md`. These reuse the project's own church painters and preserve shader code, material identity and other uniforms.
