# Quay props reference, 2026-09-26

`quay-props.png` was generated with the built-in imagegen tool for this project. It is a visual
reference, not a texture pasted onto the geometry. The existing original Blender models already
match its faceted casks, recessed heads, framed crates, jute and rope. Their shipping marks now
identify a merchant, origin/contents and lot. The original shared atlas and batching are retained.

Research (primary sources checked 2026-09-26):

- [Kenney Pirate Kit](https://kenney.nl/assets/pirate-kit): 70 models, CC0. Useful simple silhouettes,
  but the colourful pirate presentation needs substantial adaptation for this town.
- [Quaternius Fantasy Props MegaKit](https://quaternius.com/packs/fantasypropsmegakit.html): 211 models,
  CC0; shared textures and low polygon counts. Fantasy ornament and newer pack presentation are less
  suitable than our existing period-specific models. No downloaded third-party assets were imported.

## Generation prompt

Use case: stylized-concept. Create a production 3D low-poly prop reference sheet for Scheldemist,
first-person PS1-style game set on Antwerp's working quays in autumn 1873. A PS1 game found in a wet
cellar: cold grey-green mist, muted weathered brown oak, black rusted iron hoops, dirty jute, wet
stone, tiny amber gas light. Show a six-cask pyramid (three lying barrels bottom row, two middle,
one top), a single upright barrel, a lying barrel on wooden chocks, framed shipping crate, tied
sacks on a pallet, and a rope coil. Main large three-quarter vignette on wet cobbles, smaller clear
front and side silhouettes against fog-grey background for modeling. Believable human scale,
faceted 12-sided bulging oak casks, four dark iron hoops, recessed wooden heads, uneven stave tones,
restrained pixelated hand-painted textures, worn edges. Clearly separate round barrels with visible
wedge-shaped gaps around the pyramid, no box enclosing the pile. Not cute, no fantasy ornaments,
no modern labels or logos, no glossy plastic. Readable shapes and grounded contacts, soft overcast
lighting with one faint warm lamp in the far fog. Original assets. Landscape composition. No text
or watermark.
