# Native gameplay service conversion

Godot calls `INativeServiceBackend.Call(method,path,json,playerId)` in process. SQLite holds ownership, money, needs, jobs, memories and world state. Unimplemented routes throw 501; `CanHandle` describes actual registrations. Route coverage alone does not establish gameplay parity.

## Adding a rule module

Implement `INativeServiceModule` under `src/Services`, register its real routes and wire it in `src/World/NativeTownGame.cs`. Reuse the host's context and existing module hooks. SQL values use `$p0` parameters. Clone a JSON node before adding it to another parent.

Synchronous handlers already hold the state lock. Narration handlers use `RegisterAsync` and short `await host.WithState(...)` sections before and after the provider call. Freeze context into JSON, release the lock, then await narration. Never call an asynchronous provider with `.Result`. Recheck generation, ownership and deadlines before applying returned words. Payments and random outcomes remain engine rules.

Clock epochs differ in the original game: `Clock.MinuteNow()` is `day*1440+hour*60+minute`, used by interiors and rest; `Clock.GameMinute()` subtracts 1440, used by deeds, actions and night task deadlines. Keep the appropriate epoch when porting persisted timestamps.

## State and extension points

`NativeServiceHost` owns clock, trade, jobs, saves, rest, rumours, homes, interiors and night work. District and town modules add their routes and hooks. Preserve existing callbacks when adding room resolvers, shop restrictions or price modifiers.

`NarrateAsync(player,hook,request)` accepts frozen `system`, `prompt` and JSON `schema` fields. Generated boards pass through `Jobs.Plan.TaskFor` and `FitCarry`; outcomes can change wording and memory only. Tavern dice, fire, admission, theft and rental charges never read monetary promises from narration.

Night gangs use the shared Actions perception and walk-up callbacks. They choose existing nearby thief residents, retain per-player encounters and do not create another population. Tavern chat publishes events and `Interiors.RecentConvos()` for polling. Night giver greeting/self hooks are exposed by `Night.Greeting` and `Night.AboutSelf`.

Register every module before setting `Jobs.NarrateAsync`: setting that hook may start the first board and its morning callbacks. Press announcements call the actual event planner; `Press.RollNews` connects the Ideas price/news rules. Songs chain `Events.StageAct` and add an interior guest provider. Preserve earlier callbacks. Native hired-hand deliveries are settled by `NativeHands.After`; the Godot walker must not award the same job progress again.

Call `Ideas.Start()` after its callbacks are wired. `TickAfterHooks` checks notices after every tick request, including requests that do not advance time; `TickHooks` retains its advancing-tick behavior. `SleepEndedHooks` runs after a real long-rest/collapse night increment, allowing dream work without triggering it when a player stays awake. `Walkup.CustomsTrouble = Ideas.CustomsTrouble` creates the engine scene immediately and writes optional narration asynchronously.

`native-night.json` contains authored spot data and distances recovered from the original static walk map. `Jobs.Plan.DistanceResolver` can replace these distances when the native navigation map changes. Permanent place and resident IDs must remain stable across scene edits and saves.

Frontend population holders subscribe to `Townspeople.PopulationChanged` after the new town is installed. Posted employers, market keeper lists, pets, visitors, hall rosters and map places discard previous records; unsubscribe on exit. Guard pending polls and route replies with a population revision so an old response cannot restore old people. Resettable tables use `WalkMap.RegisterBody` and actual colliders, allowing their removal without leaving permanent `AddBox` cells. Long routes follow static support; the crowd checks current bodies locally.

$extrasPreviousData = $env:SCHELDEMIST_USER_DATA
try {
    $env:SCHELDEMIST_USER_DATA = Join-Path $extrasOutput 'userdata'
