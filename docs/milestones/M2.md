# M2 - Server and job board, 2026-09-23

Goal (docs/06): the server runs. Claude writes a job board. It shows in the game. One carry job works.

## How to run
```
cd D:\Code\MoodyGame
npm run setup    # once: installs root, server and client packages
npm run dev      # starts the server and the game together
```
Open http://localhost:5173. Walk to the notice board in front of the HESSENATIE warehouse. Press E.
To start over, stop the servers and delete `data/game.sqlite`. The next start writes a new board.

## What is in
| Part | Where | Notes |
|---|---|---|
| Server | `server/src/index.ts` | Node 24, runs TypeScript directly. Hono on 127.0.0.1:8787 only. WebSocket `/ws` pushes the board when it is ready. |
| Database | `server/src/db.ts` | All tables from docs/04. Seeds Jef (50 c, day 1, dawn), five factions at trust 0, the 8 town NPCs (no personas yet). |
| Claude call | `server/src/ai/claude.ts` | Agent SDK, local login. `claude-opus-5-5`, effort medium, `tools: []`, own system prompt, JSON schema output, `maxTurns: 1`, no session files, no settings or CLAUDE.md loaded, runs in an empty folder. 20 s limit. Schema failure gets one retry. One call in flight per hook. 80 calls per game day at most. Every call is a row in `ai_call`. |
| job_board hook | `server/src/hooks/jobBoard.ts` | Claude writes titles and pitches. The engine clamps pay to the tier band (tier 0: 50-150 c), decides crates and spots, and makes sure one carry job exists. Hand-written fallback board if Claude is late or wrong. |
| Game rules | `server/src/game.ts` | Take a job (one at a time, playable types only). Finish it: the server checks the crate count and pays the job's own pay. The client never sends money. |
| Client | `client/src/game/jobs.ts`, `client/src/net/api.ts` | Notice board, paper job list, carry job: crates at the source spot, E to lift, E to set down on the chalk ring. Carrying slows you to 62 %. Task note top left, money bottom left. |
| One command | `package.json` (root) | `concurrently` runs server and client. Vite forwards `/api` and `/ws` to the server. |
